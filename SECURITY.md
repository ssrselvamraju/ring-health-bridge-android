# Security policy

Please report vulnerabilities privately to the repository maintainer through a
private GitHub Security Advisory. If private reporting is not enabled, open a
minimal issue asking for a private contact channel without including technical
details or sensitive material.

Never attach or paste ring authentication keys, health databases, raw BLE captures,
Android backups, crash dumps, device addresses, serial numbers, personal diagnostic
reports, or real health exports into a public issue, pull request, discussion, or
chat. Redaction is easy to get wrong; prefer a synthetic reproducer.

This experimental project does not promise security-update timelines. It is not a
medical device and should not be relied on for clinical or emergency decisions.
